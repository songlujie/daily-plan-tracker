# 每日方案记录

直接双击 `index.html` 使用，或运行 `python3 -m http.server 4173` 后访问 `http://localhost:4173`。

数据保存在当前浏览器。记录不按日期拆分，而是始终在原来的历史基础上持续累积；命中后回到基础档，未中后下一次自动翻倍，每个方案独立计算。
每次新增、编辑或记录结果后会自动写入主存储和本地备份，页面更新或重新打开时会自动恢复。
新增方案时，方案名称支持从已有名称下拉选择，也可以直接输入新名称；新名称保存后会自动进入下拉列表。

纯利计算：命中为 `本金 ×（实际赔率 - 1）`，未中为 `-本金`；页面会汇总每个方案纯利和全部记录的累计总利润。
